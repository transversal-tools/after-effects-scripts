# Notes for coding agents

## Where this repository lives

- Official home: **github.com/transversal-tools/after-effects-scripts** (remote `origin`). Issues, releases and all new work go here.
- `github.com/pdrmafra/after-effects-scripts` is the old copy, frozen on purpose. Never push, tag or release there. Don't use it as the current source either. Locally it may exist as the remote `pdrmafra`.
- The transversal.tools website has its own repository (`transversal-tools/transversal.tools`); it is not part of this one.

## Git and Dropbox

- The working files may sit in Dropbox, but the git data must stay outside it. If `.git` is a one-line file pointing to `~/git/after-effects-scripts.git`, keep it that way: never turn it back into a `.git` folder and never `git init` or clone inside Dropbox. New repositories go in `~/git`.

## Working rules

- Sources are in `src/` and `experimental/shape-to-stroke/*.jsxinc`. `scripts/*.jsx` and `experimental/shape-to-stroke/Shape-to-Stroke.jsx` are generated by `npm run build`; never edit them by hand.
- Run `npm run check` after any code change (stale-build check plus the Node tests). See `docs/development.md`.
- Push, release or change GitHub settings only after the owner explicitly approves. Push straight to `main` (no pull requests). Publish releases as pre-releases (Windows is untested).
- Never say something works in After Effects unless it was tested in After Effects. Say plainly what was only tested in Node.
- Scripts are signed **Transversal**. Internal names such as `PedroAE`, `PedroStroke*` and the `app.settings` sections `PedroMafra.*` stay as they are: renaming the settings sections would wipe users' saved options.
